# Nikhil Yadav — Cybersecurity Portfolio

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript, populated from Nikhil Yadav's supplied resume.

## Files
- `index.html` — portfolio content and sections
- `style.css` — responsive dark theme and layout
- `script.js` — mobile navigation and current year
- `resume.pdf` — resume PDF for the “View Resume” buttons
- `nikhil-profile.jpg` — profile photo used in the hero section
- `nikhil-graduation.jpg` — graduation photo in the personal gallery

## Run locally
Open `index.html` in a browser. No build tools are required.

## Publish with GitHub Pages
1. Create a repository on your GitHub account (for example, `nikhil-yadav-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, `resume.pdf`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the deployment status and open the published URL shown by GitHub Pages.

## Before publishing
- Replace `YOUR_TWITTER_USERNAME` in `index.html` with your actual X/Twitter username, or remove those links if you do not use X.
- Confirm the resume details and social profile links.
- Review all files for personal information you do not want to publish.
- Do not add passwords, API keys, `.env` files, datasets with restricted licenses, or sensitive lab information.
